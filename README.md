# Norway vs England - Pre Match Analysis

A pre-match football data analysis project for the FIFA World Cup 2026 Quarter-final between Norway and England.

## Objectives

- Analyze both teams using football data.
- Compare player performances.
- Identify tactical strengths and weaknesses.
- Build a data-driven pre-match report using Python.

## Tools

- Python
- Pandas
- Matplotlib
- mplsoccer

> This project is part of my Football Data Analytics portfolio.
